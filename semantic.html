Pengertian PPLG

PPLG adalah singkatan dari Pengembangan Perangkat Lunak dan Gim. Jurusan ini mempelajari berbagai hal tentang pembuatan perangkat lunak, website, aplikasi, serta gim menggunakan teknologi komputer.

Kompetensi yang Dipelajari

  • HTML dan CSS
  • JavaScript
  • Pemrograman berbasis web
  • Pembuatan aplikasi
  • Basis data
  • Pengembangan gim

Prospek Kerja

Lulusan PPLG memiliki berbagai peluang kerja di bidang teknologi, seperti Web Developer, Software Developer, Game Developer, UI/UX Designer, dan Database Administrator.

Kegiatan Siswa PPLG

Siswa PPLG melakukan berbagai kegiatan praktik untuk meningkatkan keterampilan di bidang teknologi. Kegiatan tersebut meliputi pembuatan website, aplikasi sederhana, desain antarmuka, pengelolaan database, dan pembuatan proyek gim.

Selain pembelajaran di kelas, siswa juga dapat mengerjakan proyek secara berkelompok untuk melatih kreativitas, kerja sama, dan kemampuan memecahkan masalah.

Informasi Tambahan

PPLG cocok bagi siswa yang memiliki minat terhadap komputer, teknologi, pemrograman, dan pembuatan aplikasi.
